# Trash Blog 第一版
将本目录内的文件和 assets 文件夹放在网站根目录。GitHub Pages 中选择从 main 分支的 /(root) 发布。入口为 index.html。启用 Pages 后网页会公开。
## 写垃圾话
编辑根目录的 thoughts.txt。每条之间留一个空白行。普通换行仍属于同一条；只写准备公开的文字。文件当前为空，因此正式版从零团开始。提交修改，等发布完成，然后刷新首页。每个非空段落生成一个可点击的纸团。修改段落保留数量，删除段落减少数量。只更新重新打开或刷新的页面。
## 本地查看
正式版需要通过 HTTP 读取文字。可在本目录运行 python3 -m http.server 8000 --bind 127.0.0.1 并访问 http://127.0.0.1:8000 ，或使用静态服务器。原型的离线单文件版单独保留。
